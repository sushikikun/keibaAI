# Gate 2-F portable execution runbook

This bundle is for a higher-memory host. Verify SHA-256 inventory before execution. Do not use Confirmation or Final-lock rows. Run only Screening Folds 1–4 with one fit/process at a time. Start only with at least 3072 MiB available physical memory sustained for 60 seconds; stop a candidate if memory cannot recover to 2048 MiB within 60 seconds. The local source host preflight was blocked; no Gate 2-F screening run was started.
