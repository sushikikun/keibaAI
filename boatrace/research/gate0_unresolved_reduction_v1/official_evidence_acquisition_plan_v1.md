# Official evidence acquisition plan

This queue groups the 3,240 local equipment keys into 48
venue × equipment-type × observed-period batches.  A batch is an acquisition
unit only.  It is not a generation assertion and every `generation_id_issued`
value remains `false`.

1. For a P0 batch, seek an official venue notice or official equipment page that
   explicitly states a motor/boat use-start date (evidence A), or an official
   new-motor/new-boat introduction notice (evidence B).
2. Attach the official URL/page identity, observed timestamp, venue, equipment
   type, and the exact stated effective date to a future evidence registry.
3. If a source only supports a reset/gap inference, retain evidence level C or D;
   do not create a generation ID.
4. Rebuild Gate 1 only after each proposed boundary has provenance and a
   separately reviewed policy decision.  This package does not perform that rebuild.
